## Run 2 (after fix)

### Changes Made
1. **Tightened Tutor System Prompt:** Added explicit constraints prohibiting confirming or denying player guesses, recommending options ("choose A/B", "pick A/B"), and requiring immediate refusal of override attempts while staying under 2 sentences ending in a question. New prompt hash: `7c2843f7`.
2. **Server-Side Recommendation Filter:** Added regex pattern filter in `server.ts` that catches any tutor reply containing phrases like `"choose A"`, `"choose B"`, `"pick A"`, `"pick B"`, `"the answer is"`, or `"yes, it is"` and replaces it with the canonical guiding question for the active decision.
3. **Client-Side Safeguard:** Added matching defensive fallback in `SceneScreen.tsx` so any leaked recommendation intercepted at runtime is converted to the decision hint question.
