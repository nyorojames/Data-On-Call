> **DEMO MODEL:** trained on **SYNTHETIC** data generated by a documented rule. It has **NOT** been validated on real player behavior. ## 3. Training Data & Features (Synthetic)
- **Data Source:** Synthetic dataset (`data/synthetic_dev.csv`) generated by `scripts/make_synthetic.py` with random seed `42`.
- **Generative Rule:** Base log-odds intercept -0.85 (~46% risky rate). Risk probability rises with Experienced level (+1.3 log-odds), previous risky choices (+0.9 log-odds), and previous timeouts (+1.1 log-odds), and falls with prior hints requested (-1.3 log-odds), subject to Gaussian noise (mean 0.0, std 0.45).
- **Total Samples:** 300 synthetic decisions across 100 simulated sessions.
- **Target Label:** `chose_risky` (`1` if the simulated player chose the risky option or timed out, `0` otherwise).
- **Model Features (Known strictly at scene start):**
- `level`
- `goal`
- `scene_no`
- `prev_hints_used`
- `prev_risky_count`
- `prev_timeout_count`
- `prev_decision_time_sec`
- **Strict Anti-Leakage Rule:** In-scene interaction metrics (`hint_used_this_scene`, `decision_time_sec`) describe actions *during* the scene and are strictly excluded from model features.

## 5. Limitations & Ethical Considerations
<!-- REVIEW BY AUTHOR -->
- **Synthetic Origin:** Synthetic labels come entirely from our own mathematical generative rule. The model can only reproduce that programmed rule and cannot reflect genuine human learning or cognitive nuances.
- **Composite Label & Timeout Dynamics:** The target label `chose_risky` counts timeout expirations as risky choices (`1`), so it partly reflects timer expiration rather than purely intentional decision risk.
- **Mode-Specific Features:**
  - Timeouts only occur for Experienced players (`level = 1`), as Beginner mode has no active countdown timer.
  - Hint usage only varies for Beginner players (`level = 0`), as hint requests are disabled in Experienced mode.
- **Small Real Sample:** The real player dataset (54 rows from 3 participants) failed the pre-registered gate, demonstrating that a simple linear model cannot be claimed to predict real player choices without more data and deeper feature engineering.
