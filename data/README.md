# Data Directory (`data/`)

This directory contains anonymized session telemetry for Data On-Call v2 (`sessions.csv`).

## Privacy & Protection Notice (KVKK / Data Protection Compliance)
- **Zero Personal Data:** Absolutely no personal data is collected or stored.
- Complies with KVKK (Turkey's Personal Data Protection Law) and international data protection standards.
- No player names, email addresses, IP addresses, device identifiers, user-agent strings, or location metadata are logged.
- Session IDs (`session_id`) are purely random hex tokens generated client-side using cryptographically secure pseudorandom values with fallback.
- All session records represent synthetic gameplay choices made within the simulation.
