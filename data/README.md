# Data Directory (`data/`)

This directory contains anonymized session telemetry for Data On-Call v2 (`oturumlar.csv`).

## Privacy & Protection Notice (KVKK / GDPR Compliance)
- **Zero Personal Data:** Absolutely no personal data is collected or stored.
- No player names, email addresses, IP addresses, device identifiers, user-agent strings, or location metadata are logged.
- Session IDs (`oturum`) are purely random hex tokens generated client-side using cryptographically secure pseudorandom values.
- All session records represent synthetic gameplay choices made within the simulation.
